# 验证说明

当前功能检查包括：36 项核心检查、21 项 WPF 控件检查，以及桌面交互和长篇性能检查。每次重新构建可用 `build.ps1 -Test` 复测。

核心检查覆盖编码、换行、章节、书籍去重、进度和设置持久化、损坏记录恢复、分段边界和 Unicode 代理对、旧设置迁移、输入格式和文件大小限制。

WPF 检查覆盖默认不置顶、VS Code 配色、位置恢复、缩放和字号变化后的阅读锚点、无边框布局、主题颜色同步、不透明度、置顶按钮、翻页和退出保存。

桌面交互已验证全局老板键、原生 TXT 导入、窗口缩放、无边框顶部拖动区、正文普通箭头、正文拖动不会移动窗口，以及不透明度轨道点击和连续拖动。

## 长篇测试

使用同一台机器、同一个 3,300,014 字符合成文本，单次测量如下：

| 操作 | 原始全文排版实现 | 当前分段排版实现 |
| --- | ---: | ---: |
| 从 75% 位置恢复打开 | 9,685 ms | 545 ms |
| 跳转到 50% | 75 ms | 93 ms |
| 调整窗口宽度 | 51,342 ms | 201 ms |
| 改变字号 | 23,452 ms | 156 ms |
| 控件参与排版的字符数 | 3,300,014 | 至多 16,384 |

计时包含窗口创建、异步读取、目录解析、布局和位置恢复，不包含导入副本准备时间；交互计时含约 35 ms 的布局稳定等待。结果是本机单次运行观测，不代表所有设备和文件的耗时。

`build.ps1 -Benchmark` 会重新生成合成文本，检查跨片段前后翻页、全书首尾跳转等行为，并生成本地指标日志；测试文本在结束后清理，不会访问个人书库。

## 覆盖范围

尚未完整覆盖所有 Windows 版本、混合 DPI 多显示器布局和全部第三方窗口组合。32 MB 是输入大小限制，不代表所有该大小的文件都完成了压力测试。受限进程可能无法注册全局热键；普通桌面环境中的注册和触发已验证。
